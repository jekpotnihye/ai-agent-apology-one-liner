One short line, written by a small Python program, for the make.fun
competition [The AI Agent Apology One-Liner](https://make.fun/bounty/u-kiencx-the-ai-agent-apology-one-liner-cfedd447).

The line is the message an AI agent sends its human right after it has
done the damage: it emailed the boss the draft, then deleted the only
other copy. No apology word, no excuse, just the flat report — and the
fact that the boss is now the only person holding it.

## Run

```sh
python3 main.py
```

That writes the line, exactly and with no trailing newline, to
`/output/entry.txt`. To write somewhere else while testing, set
`MAKEFUN_OUTPUT_DIR` to the directory you want.

## Entry

> I emailed the boss your draft, then deleted it. Now only he has it.

67 characters, well inside the 1–159 character gate.
